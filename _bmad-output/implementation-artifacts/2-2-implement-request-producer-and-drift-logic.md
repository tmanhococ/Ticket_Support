# Story 2.2: Implement Request Producer & Drift Logic

Status: review

## Story

As a MLOps Engineer,
I want the simulator to continuously send requests — including intentionally invalid payloads at a configurable rate — and support a drift parameter,
So that I can test the system's resilience, drift detection, and verify that the API correctly rejects malformed tickets before they enter the database.

## Acceptance Criteria

1. **[AC1]** A `src/simulator/run_simulator.py` script, when executed as `python -m src.simulator.run_simulator`, starts sending POST requests to the FastAPI `/tickets/` endpoint continuously at a configurable rate (default: 1 req/s).
2. **[AC2]** The script accepts CLI arguments: `--url` (API base URL, default: `http://localhost:8000`), `--rate` (req/s, default: 1.0), `--total` (total requests, 0=infinite, default: 0), `--drift` (drift mode flag, default: False), `--invalid-rate` (float 0.0–1.0, fraction of requests that are intentionally invalid, default: 0.0).
3. **[AC3]** In **normal mode** (`--drift` not set, `--invalid-rate 0`): tickets are generated using `generate_ticket()`. The script logs each sent request with its `ticket_id` and HTTP status code.
4. **[AC4]** In **drift mode** (`--drift` flag set): tickets are generated using `generate_drift_ticket()` — a function in `src/simulator/generator.py` that biases the distribution toward `language="de"` (≥80% German), `type="Incident"` (≥70% Incident), and `queue="Technical Support"` (≥70%). Drift mode is orthogonal to `--invalid-rate` (both can be active simultaneously).
5. **[AC5]** When `--invalid-rate` > 0.0, each request has a probability equal to `invalid-rate` of sending an invalid payload generated by `generate_invalid_ticket()` from Story 2.1. The API is expected to return HTTP **422**, which the simulator logs as `[INVALID_SENT]`. Invalid tickets are **never retried**.
6. **[AC6]** HTTP responses are handled gracefully: 201 = `[SUCCESS]`, 422 = `[INVALID_SENT]` (not retried — expected rejection), other 4xx = `[VALIDATION_ERROR]` (not retried), 5xx = `[SERVER_ERROR]` (retry after 2 seconds, up to 3 times). Max retries exceeded → log WARNING and continue.
7. **[AC7]** On shutdown (CTRL+C or `--total` reached), the script prints an **ingestion funnel summary**: `Simulator stopped. Total={N} | Accepted=201:{V} | Rejected=422:{R} | Errors:{E}`.
8. **[AC8]** Unit tests verify: `generate_drift_ticket()` language distribution is ≥80% German over 100 samples, type distribution is ≥70% Incident, the output still validates against `TicketIn` schema.

**Epic 1 — API endpoint contract:**
- `POST /tickets/` returns **201** on valid payload (ticket saved to DB), **422** on Pydantic validation failure (ticket NOT saved), **503** on DB write failure.
- The 422 response is the API's **rejection gate** — it guarantees no invalid record enters PostgreSQL.
- The simulator must treat 422 as an **expected, intentional outcome** when `--invalid-rate > 0`, not an error. Log it distinctly as `[INVALID_SENT]` to differentiate from unexpected 4xx.

### `generate_drift_ticket()` Implementation Pattern
```python
# ADD to src/simulator/generator.py (do NOT create a new file)

def generate_drift_ticket(seed: int | None = None) -> dict:
    """
    Generate a ticket with biased distribution to simulate Data Drift.

    Bias:
    - Language: 80% German (de), 20% English (en)
    - Type: 70% Incident
    - Queue: 70% Technical Support
    """
    if seed is not None:
        random.seed(seed)

    language = random.choices(["en", "de"], weights=[20, 80])[0]

    if language == "en":
        idx = random.randrange(len(SUBJECTS_EN))
        subject = SUBJECTS_EN[idx]
        body = BODIES_EN[idx]
    else:
        idx = random.randrange(len(SUBJECTS_DE))
        subject = SUBJECTS_DE[idx]
        body = BODIES_DE[idx]

    return {
        "ticket_id": str(uuid.uuid4()),
        "timestamp": datetime.now(timezone.utc).isoformat(),
        "subject": subject,
        "body": body,
        "language": language,
        "queue": random.choices(
            QUEUES, weights=[70, 10, 10, 5, 5]
        )[0],
        "type": random.choices(
            TYPES, weights=[70, 10, 15, 5]
        )[0],
    }
```

### `run_simulator.py` Implementation Pattern
```python
# src/simulator/run_simulator.py
import argparse
import logging
import random
import time
from dataclasses import dataclass, field

import httpx

from src.simulator.generator import (
    generate_drift_ticket,
    generate_invalid_ticket,
    generate_ticket,
)

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(message)s",
)
logger = logging.getLogger(__name__)


@dataclass
class Counters:
    total: int = 0
    accepted: int = 0      # 201
    rejected_422: int = 0  # 422 — expected rejection of invalid payloads
    errors: int = 0        # other 4xx, 5xx, connection errors

    def summary(self) -> str:
        return (
            f"Total={self.total} | "
            f"Accepted=201:{self.accepted} | "
            f"Rejected=422:{self.rejected_422} | "
            f"Errors:{self.errors}"
        )


def parse_args() -> argparse.Namespace:
    parser = argparse.ArgumentParser(description="Ticket Stream Simulator")
    parser.add_argument("--url", default="http://localhost:8000", help="API base URL")
    parser.add_argument("--rate", type=float, default=1.0, help="Requests per second")
    parser.add_argument("--total", type=int, default=0, help="Total requests, 0=infinite")
    parser.add_argument("--drift", action="store_true", help="Enable drift mode")
    parser.add_argument(
        "--invalid-rate",
        type=float,
        default=0.0,
        dest="invalid_rate",
        metavar="RATE",
        help="Fraction of requests that are intentionally invalid (0.0–1.0, default: 0.0)",
    )
    args = parser.parse_args()
    if not 0.0 <= args.invalid_rate <= 1.0:
        parser.error("--invalid-rate must be between 0.0 and 1.0")
    return args


def send_ticket(
    url: str,
    payload: dict,
    is_invalid: bool = False,
    retries: int = 3,
) -> int:
    """
    POST ticket to API. Returns final HTTP status code.
    - Valid tickets: retry up to `retries` times on 5xx.
    - Invalid tickets: never retried (422 is the expected outcome).
    """
    target = f"{url}/tickets/"
    max_attempts = 1 if is_invalid else retries
    ticket_id = payload.get("ticket_id", "<missing>")

    for attempt in range(1, max_attempts + 1):
        try:
            response = httpx.post(target, json=payload, timeout=10.0)
            status = response.status_code
            if status == 201:
                logger.info("[SUCCESS] ticket_id=%s status=201", ticket_id)
                return status
            elif status == 422:
                if is_invalid:
                    logger.info("[INVALID_SENT] ticket_id=%s status=422 — expected rejection", ticket_id)
                else:
                    logger.warning("[VALIDATION_ERROR] ticket_id=%s status=422 — unexpected", ticket_id)
                return status
            elif 400 <= status < 500:
                logger.warning("[CLIENT_ERROR] ticket_id=%s status=%d", ticket_id, status)
                return status
            else:  # 5xx
                logger.warning(
                    "[SERVER_ERROR] ticket_id=%s status=%d attempt=%d/%d",
                    ticket_id, status, attempt, max_attempts,
                )
                if attempt < max_attempts:
                    time.sleep(2)
        except httpx.RequestError as exc:
            logger.warning(
                "[CONNECT_ERROR] ticket_id=%s attempt=%d/%d error=%s",
                ticket_id, attempt, max_attempts, exc,
            )
            if attempt < max_attempts:
                time.sleep(2)

    logger.warning("[MAX_RETRIES] ticket_id=%s — skipping", ticket_id)
    return -1


def run(args: argparse.Namespace) -> None:
    mode = "DRIFT" if args.drift else "NORMAL"
    base_generator = generate_drift_ticket if args.drift else generate_ticket
    logger.info(
        "Starting simulator | mode=%s invalid_rate=%.0f%% url=%s rate=%.1f req/s",
        mode, args.invalid_rate * 100, args.url, args.rate,
    )

    counters = Counters()
    interval = 1.0 / args.rate

    try:
        while True:
            # Decide: valid or invalid request?
            is_invalid = random.random() < args.invalid_rate
            payload = generate_invalid_ticket() if is_invalid else base_generator()

            status = send_ticket(args.url, payload, is_invalid=is_invalid)
            counters.total += 1
            if status == 201:
                counters.accepted += 1
            elif status == 422:
                counters.rejected_422 += 1
            else:
                counters.errors += 1

            if args.total > 0 and counters.total >= args.total:
                break

            time.sleep(interval)
    except KeyboardInterrupt:
        pass

    logger.info("Simulator stopped. %s", counters.summary())


if __name__ == "__main__":
    run(parse_args())
```

# tests/test_drift.py
from src.api.schemas import TicketIn
from src.simulator.generator import generate_drift_ticket, QUEUES, TYPES


def test_drift_ticket_validates_as_ticket_in():
    ticket_dict = generate_drift_ticket()
    ticket = TicketIn(**ticket_dict)
    assert ticket.subject
    assert ticket.body


def test_drift_language_is_mostly_german():
    results = [generate_drift_ticket() for _ in range(100)]
    german_count = sum(1 for r in results if r["language"] == "de")
    assert german_count >= 80, f"Expected ≥80 German tickets, got {german_count}"


def test_drift_type_is_mostly_incident():
    results = [generate_drift_ticket() for _ in range(100)]
    incident_count = sum(1 for r in results if r["type"] == "Incident")
    assert incident_count >= 70, f"Expected ≥70 Incident tickets, got {incident_count}"


def test_drift_queue_is_mostly_technical_support():
    results = [generate_drift_ticket() for _ in range(100)]
    ts_count = sum(1 for r in results if r["queue"] == "Technical Support")
    assert ts_count >= 70, f"Expected ≥70 Technical Support tickets, got {ts_count}"
